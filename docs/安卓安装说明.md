# 安卓安装说明

APK 由 `scripts/build-apk.ps1` 生成后,出现在项目 `dl/` 目录,或通过手机浏览器访问
`http://<电脑地址>:8790/dl` 下载(需与电脑同一 Wi-Fi,或两端都在 Tailscale 网络)。

## 安装步骤

1. 手机浏览器打开下载页 → 点 `todo-reminder-v0.1.0.apk` 下载
2. 首次安装系统会提示「未知来源」→ 允许本次安装(小米/华为等需在「纯净模式/安全中心」确认)
3. 安装完成后打开「待办提醒」→ 会引导去「设置」填写:
   - **服务器地址**:电脑端软件「设置 → 同步与连接」里显示的地址
     - 同一 Wi-Fi:`http://192.168.x.x:8790`
     - 外出(Tailscale):`http://100.x.x.x:8790`
   - **连接码**:同一页面显示的一串字符
4. 点「测试连接 / 立即同步」,状态显示 ✅ 后即可使用

## 必须做的提醒权限(建议按顺序)

| 权限 | 入口 | 作用 |
|---|---|---|
| 通知权限 | 设置 → 通知权限(Android 13+) | 显示提醒横幅 |
| 精确闹钟 | 设置 → 精确闹钟权限 | 到点准时提醒(不给则可能延迟几分钟) |
| 忽略电池优化 | 设置 → 忽略电池优化 | 防止系统杀后台导致提醒不响 |
| 自启动 | 系统设置 → 应用 → 待办提醒 → 自启动(国产 ROM 特有,如 MIUI/ColorOS/EMUI) | 保持后台 |

设置页有「发送测试通知」和「8 秒后测试闹钟」可即时验证。

## 提醒机制说明

- 提醒由**手机本地闹钟**触发:App 打开过并把数据同步到手机后,即使 App 没开也会响
- 重启手机后自动恢复提醒(开机广播重排)
- 从设置里「强行停止」App 后,需重新打开一次 App(安卓系统限制,所有同类应用一致)
- 手机与电脑数据在每次打开 App、每 30 秒及每次改动时自动同步(需在同一网络)

## 常见问题

- **连不上服务器**:检查电脑端是否在运行;同一 Wi-Fi 时关掉手机流量;两端都装 Tailscale 时确认电脑端已 `tailscale up`
- **提示连接码错误**:电脑端设置页点「重置连接码」后,在手机设置里更新
- **想卸载重装/换手机**:数据都在电脑端,新手机装好连上即自动全量同步
