【一、这是什么】
一个“个人待办 + 课程表/时段 + AI 识图”跨端工具。三个形态共用一套 Web UI:
 1. Windows 桌面(Electron + 内置服务器 127.0.0.1:8790,含系统通知提醒)
 2. 手机浏览器连电脑网页(需电脑在线 + Tailscale/局域网)
 3. 【手机一体包 APK】= 内嵌整套 Web 页面 + 手机本地服务器(127.0.0.1:8790)
    数据存手机本地且【手机为主】,APK 意义=拿系统通知/精确闹钟权限;
    UI 完全本地运行(已用飞行模式实测),卡顿与网络无关,只与渲染有关。

【十、踩坑与禁忌(新对话必读)】
  - PowerShell 里中文 JSON 会被按 GBK 发送而乱码: 用 node/UTF-8 脚本或 write 工具。
  - electron 命令行传“路径样式的多余参数”会启动即崩: 改用环境变量传参。
  - 模板串里 \n 会被提前转义成真换行,注入页面代码语法崩: 用 String.fromCharCode(10)。
  - Vue computed 之间引用绝不能带括号(此 bug 造成整页白屏,已修两处,勿再犯)。
  - v-for 与 v-if 不能同元素(Vue3 优先 v-if,会用未定义变量)。
  - LocalServer 请求体必须只按 Content-Length 读(keep-alive 下读到 EOF 会死锁),
    并按 UTF-8 解码(parseBody 默认解码会乱码); 响应统一 Connection: close。
  - prepareWebDir 版本号感知: 升级后自动整包刷新 filesDir/web(勿改回“只解压一次”)。
  - 别在用户真实数据(8790/%APPDATA%)上乱写; 试验一律走隔离实例或 android-sim。
  - 白屏相关字段: MainActivity 的 onRenderProcessGone 自愈/防循环/软渲染回退
    20 秒自动恢复硬件; 崩溃留痕在 files/local-log.txt([native] renderer-gone)。
  - 引擎细节: localStorage tr:v1:{todos,periods,meta,token}; __NO_WS__ 模式无 WS;
    window.__errs(错误)、window.__perf(耗时)在诊断信息中可复制。
  - 一键更新: /api/phone/update 匹配 todo-reminder-phone-vX.Y.Z.apk 且要求
    versionCode 严格递增; Android8+ 需“安装未知应用”授权(已引导)。
