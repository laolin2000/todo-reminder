# 文件投递约定 —— 电脑 → 手机/其它设备

**唯一可用通道**：`http://100.119.164.72:8790/dl/`（Tailscale IP + 「待办提醒」桌面端内嵌服务器）

## 目录位置

| 项 | 值 |
|---|---|
| 公开地址 | http://100.119.164.72:8790/dl/ |
| 磁盘目录 | `C:\Users\<you>\AppData\Roaming\待办提醒\downloads` |
| 服务进程 | `TodoReminder\node_modules\electron\dist\electron.exe`（端口 8790，托盘常驻） |
| 鉴权 | `/dl/` 为免鉴权公开静态目录（Tailscale 内网可见）→ **不要投递隐私文件** |

## 投递一个文件

```powershell
# 方式一: 直接拷贝（最快）
Copy-Item 'D:\path\to\你的文件.pdf' "$env:APPDATA\待办提醒\downloads\" -Force

# 方式二: 用脚本（自动校验大小 + 打印可点链接）
& 'D:\toolresources\DSHStool\TodoReminder\scripts\deliver.ps1' -Paths 'D:\path\to\文件1.pdf','D:\path\to\文件2.docx'
& 'D:\toolresources\DSHStool\TodoReminder\scripts\deliver.ps1' -List      # 查看当前投递内容
& 'D:\toolresources\DSHStool\TodoReminder\scripts\deliver.ps1' -Ascii -Paths 'D:\path\to\中文名.pdf'   # 转 ASCII 文件名
```

拷进去即可被 HTTP 访问，**无需重启服务**（静态目录实时读取）：
`http://100.119.164.72:8790/dl/` + `URL编码后的文件名`

## 文件名建议

手机浏览器对中文文件名/中文 URL 偶尔会保存成乱码，重要文件建议同时放一份 ASCII 名副本
（如 `speech-cn-en-3min.pdf`）。当前 `/dl/` 内的示例：

- `speech-cn-en-3min.pdf` / `speech-cn-en-3min.docx` —— 大学新生演讲稿（中英对照，3 页 A4）
