# Todo Reminder

> 跨端待办应用：Electron 桌面端 + 网页端 + 安卓一体包，自带同步服务

## 运行方式

```
npm install && npm start   # 桌面端；安卓端见 scripts/build-apk.ps1
```

## 说明

- AI 识图功能走 OpenAI 兼容接口，密钥留空：可在设置页填入，或把默认值改为读环境变量。
- `dsh-remote.keystore`、APK 产物、截图与验证记录均未入库。

## 关于本仓库

- 本仓库为个人项目备份，只包含**程序本体**：不含运行时数据、日志、缓存、构建产物与任何密钥。
- 配置中的密钥一律留空，请自行填入（或改用环境变量）。
- 路径中的 `C:\Users\<you>` 表示你自己的用户目录。
